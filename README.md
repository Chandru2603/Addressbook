# AddressBook

A console-based Address Book application developed using C programming.

## Features

- Add contacts
- Search contacts
- Edit contacts
- Delete contacts
- Display contacts
- Save contact data
- Exit with save option

## Technologies

- C Programming
- File Handling
- Structures
- Pointers
- Dynamic Memory Allocation
- Functions

## How to Run

Compile the program:

gcc addressbook.c -o addressbook

Run:

./addressbook
